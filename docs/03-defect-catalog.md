# Каталог дефектов — Desktop QA Sandbox

Все дефекты заложены намеренно (учебный стенд) и воспроизведены вручную.
Ссылки на код — по файлам `src/DesktopSandbox/`.

Шкала severity: **Critical** — неверные финансовые данные/потеря данных, **Major** — сценарий работает неправильно,
**Minor** — заметное неудобство, **Trivial** — косметика.

## D-01

**E-mail без домена верхнего уровня принимается**

| Поле | Значение |
|------|----------|
| Severity / Priority | Major / High |
| Компонент | Registration → валидация e-mail |
| Воспроизводимость | 100 % |
| Evidence | `evidence/07-invalid-email-accepted.png` |

**Шаги:** First `QA`, Last `Tester`, Email `user@domain`, Age `25`, пароль валидный → Save.

**Ожидаемый результат:** ошибка «e-mail format is invalid».

**Фактический результат:** «Saved successful».

**Причина:** `Rules.cs`, регулярное выражение `^[^@\s]+@[^@\s]+$` не требует точки и TLD.

**Рекомендация:** использовать проверку с TLD (`^[^@\s]+@[^@\s]+\.[A-Za-z]{2,}$`) или `MailAddress` + проверку домена.

| Severity / Priority | Major / High |

| Воспроизводимость | 100 % |

**Шаги:** Orders → дважды нажать «Apply 10% discount».

## D-05

**Итог не пересчитывается после удаления и фильтрации**

| Поле | Значение |
|------|----------|
| Severity / Priority | Critical / High |
| Компонент | Orders → итог |
| Воспроизводимость | 100 % |
| Evidence | `evidence/04-delete-total-stale.png` |

**Шаги:** Orders (итог 437.44) → удалить Alpha Corp (100.00).

**Ожидаемый результат:** `Total: $337.44`.

**Фактический результат:** `Total: $437.44` — сумма удалённой строки осталась.

**Причина:** `OnDelete` не вызывает `UpdateTotal`; `OnSearch` также не пересчитывает итог после фильтрации.

**Рекомендация:** единая функция пересчёта, вызываемая после любого изменения коллекции; тест на согласованность
«строки ↔ итог».

**Суммы сортируются как текст**

| Поле | Значение |
|------|----------|
| Severity / Priority | Minor / Medium |
| Компонент | Orders → таблица |
| Воспроизводимость | 100 % |
| Evidence | `evidence/06-sort-text.png` |

**Шаги:** Orders → Reset → клик по заголовку Amount.

**Ожидаемый результат:** 0.99, 3.20, 5.50, 12.00, 20.00, 45.75, 100.00, 250.00.

**Фактический результат:** 0.99, 100.00, 12.00, 20.00, 250.00, 3.20, 45.75, 5.50.
